# Python-Data-Visualization
This project is based on data visualization using Python. I used the Taxis dataset from Seaborn to explore and visualize taxi trip information.
## Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Tasks Performed
1. Loaded the Taxis dataset.
2. Checked and handled missing values.
3. Created a Line Chart.
4. Created a Bar Chart.
5. Created a Pie Chart.
6. Created a Histogram.
7. Created a Box Plot.
8. Created a Count Plot.
9. Created a Scatter Plot.
10. Created a Heatmap.
11. Created a Pair Plot.
12. Created a Violin Plot.

## Conclusion
Through this assignment, I learned how to handle missing values and create different types of visualizations using Python libraries.
